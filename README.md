An offline GTA VI trophy guide and tracker for all 55 official PS5 trophies: every official name, description and grade kept verbatim (1 platinum, 2 gold, 6 silver, 46 bronze, 28 hidden), with an original cited walkthrough, per-trophy steps, a three-stage platinum roadmap, a missable watchlist, spoiler-safe reading and portable JSON backup. No accounts, no network calls: the whole guide is static files and your progress lives in this browser.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
node serve.ts   # then open http://localhost:8080
```
